# Public Showcase Runbook

## Purpose

This is an OSYSTIC public showcase repository. It contains sanitized, portfolio-safe material only. It must never contain implementation source, client-identifying information, credentials, private URLs or internal infrastructure details.

## Operating Rules

- Keep the repository aligned with the approved `public-showcase` classification in `.osystic/repository.yml`.
- Changes require pull requests reviewed by the repository owner.
- Do not add implementation source files (`.py`, `.js`, `.ts`, `.cpp`, `.c`, `.h`) or binaries that embed private material.
- If a disclosure-boundary or exposure is suspected, stop and escalate to the owner.

## Handover

Record any regeneration steps, source-of-truth reference (without private links) and publication decisions in this file before operational handover.
