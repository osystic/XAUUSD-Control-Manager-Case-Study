# Disclosure boundary

## Allowed in this public showcase

- anonymized problem statement;
- architecture and control semantics;
- public-safe validation methodology;
- technology stack;
- evidence-backed outcome wording.

## Excluded

- client identity or social handles;
- account numbers, order tickets, broker login details, or terminal profiles;
- private screenshots or chat transcripts;
- contract, milestone, or payment details;
- private repository URLs or Git history;
- `.mq4` / `.ex4` implementation source;
- credentials, endpoints, or private infrastructure.

This repository has an independent sanitized history and is not a fork or mirror of the delivery repository.
